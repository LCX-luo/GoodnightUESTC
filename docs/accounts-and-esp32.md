# 账号资料库与 ESP32 接入

## 准备账号

1. 启动本机网页，打开 `http://127.0.0.1:8090/accounts`。
2. 新建账号备注，完成学校登录与绑定本人微信扫码授权。
3. 地图选择本人实际位置，保存位置后点击“保存添加到库”。
4. 顶部展示资料完整且已保存的账号，选择后可重新登录更新。

每个账号有独立目录、加密密钥、会话、微信凭据与 CSRF。页面不显示 Cookie、code、token 或票据，不提供签到或凭据明文导出。学校密码不写入资料库。账号目录位于 `private-data/profiles`，不能上传。

## ESP32 接手入口

请从 [ESP32 关键组件与 Agent 部署指引](../esp32/README.md) 开始。公开目录提供核心组件、示例分区、公共测试向量和 USB 配置工具；由读者的 Agent 根据实际芯片、Flash、网络与工程环境接入。

设备账号必须逐个获得本人授权，配置的地点应为本人实际位置。默认导入关闭自动调度；先逐账号验证只读取票，再确认真实提交，最后才考虑启用每日任务。code 与操作票据每次新取，不能当长期常量。

## 当前验证边界

资料库隔离、地图、显式保存和更新已通过模拟测试与 Edge 验证。设备完成原生自检、联网和两个账号 USB 导入；完整设备取票与签到仍在验证。

保存的旧学校会话曾在电脑与设备均返回 4001。后续电脑只读验证表明，已授权微信凭据可经新 code、check-bind 建立新学校会话，核对学号后直接读取当天记录成功。新设备代码已按此调整，不能据电脑成功直接宣称设备成功。

资料库保存状态不代表凭据当前仍有效。微信刷新授权可能失效；接口变更或授权撤销后仍需本人重新操作。
