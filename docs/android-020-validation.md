# Android 0.2.0 本地验证

日期：2026-10-24。只在本地构建、安装和提交，未推送。

保留原学校网页登录、国内 GCJ-02 地图和最终确认界面。新增手机内置 Python 3.13 协议环境、二维码授权、凭据刷新入口、微信绑定学校身份核对和操作票据。学校 Cookie 不传给腾讯；微信凭据由 Android Keystore AES-GCM 加密，不返回 WebView。代码不使用 Root、微信注入或手机抓包。

手机上的二维码可截图后尝试微信扫一扫从相册识别，是否接受取决于微信策略；不保证可以替代跨设备扫描。未实现未经配置的 OpenSDK 直接授权。首次授权后可尝试复用、刷新，但不是永久授权。

用户随后实测：微信拒绝相册识别，提示必须使用摄像头、图片不可用。因此当前同手机截图扫码路线失败。用户决定暂停手机完善，集中电脑端；另一屏幕展示后摄像头扫描是可选交互替代，尚未验证手机完整取票。不得把当前 APK 宣称为已可用的独立同机扫码成品。

正式提交前核对账号、时段、范围和当天记录，再取得票据；保存防重复标记后仅提交一次，之后回读学校记录。票据只保存在内存并在请求后清除。保留原有按日期的全局防重限制，换账号也不能绕过当天未知提交结果；APK 不是多账号批量客户端。

## 验证结果

- Gradle assembleDebug、assembleDebugAndroidTest、lintDebug 通过。
- 桌面 4 项手机协议适配测试通过，包括与已验证 SDK 的签名字节对照、两类会话与两个 code、账号不匹配时停止，以及授权组件禁止学校业务写接口。
- 在用户明确授权的 USB 手机 PHK110 上使用 adb install -r 覆盖安装成功：versionCode=3、versionName=0.2.0，没有卸载或清除应用数据。
- 真机 instrumentation 30 项断言通过，验证 Android 内置 Python、AES-GCM、协议模块导入，以及模拟的只读、坐标、一次提交、回读和超时不重发。全部使用模拟学校接口，没有真实账号签到。
- 多账号授权网页的后端隔离测试及 Edge 桌面/移动布局测试通过，未使用额外账号登录。

手机实际扫码、OAuth、真实网络 MMTLS 和学校取票还需本人从界面验证。本机电脑的真实签到成功不能替代手机端验证，不能宣称手机已真实端到端通过。跨日、长期刷新和账号风控同样没有保证。

APK 位于 downloads/GoodnightUESTC-Android.apk，约 39 MB；SHA256SUMS 与其对应。原始小程序反编译资料、私有缓存、密钥、签名私钥和账号文件均不提交。
