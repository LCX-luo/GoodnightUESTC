# Android 手机版

当前发布版本 **0.2.5** 支持 Android 8.0+ 的 arm64-v8a / x86_64，内置 Python 3.13 和微信协议，不需要 Root 或模拟器。国内高德地图保持不变。首次微信授权仍需要摄像头扫码：当前应用宝二维码不接受同手机截图相册识别；可将二维码展示到另一台设备再用本人微信扫描。**未实现直接跳转微信完成授权，不能承诺单手机首次独立授权。** 已保存且仍有效的凭据可复用刷新，不必每次扫码。

本次将授权任务从 Activity 中移出：切去微信或 Activity 重建不再取消同一二维码和轮询，返回恢复原任务。整个进程被系统结束时无法延续网络请求，将提示重新授权；无需 Root 或新增保活权限。诊断日志只含固定阶段和生命周期事件，不记录二维码、账号票据或凭据。

同时修复扫码后的应用宝回调缺少 `login_type=WX`、长轮询超时错误终止，以及误用已有记录作为本次提交成功依据的问题。构建与 lint、38 项真机模拟断言通过；11 项桌面协议模拟测试覆盖回调和超时。实际手机扫码取票、加密保存、免重复扫码取票和只读查询已成功；尚未验证手机新建签到记录。轮询短暂断连使用同一二维码有限重试后恢复。详见 [真机记录](../docs/android-024-validation.md)。

## 下载和使用

1. 从仓库的 [安装包目录](../downloads/) 下载 `GoodnightUESTC-Android.apk`，在手机中打开安装。需要时，允许当前浏览器或文件管理器安装此 APK。
2. 打开“晚安成电”，点击“学校账号登录”，在学校官方统一认证网页输入本人账号、密码，并按提示完成验证码或二次验证。
3. 登录完成后点击底部“完成登录，返回检查”。应用只读查询当天记录，显示“会话有效”后即可使用。若学校网页要求继续跳转，请先完成该流程。
4. 点击“显示二维码 / 验证授权”，用绑定当前学校账号的本人微信摄像头扫描并确认。可将二维码展示在另一台设备上再扫码；不要依赖相册识别。返回应用，等待“取票成功”。
5. 在地图选择本人实际位置，可查看沙河 / 清水河，或输入 GCJ-02 坐标。查看校区不会改选点。
6. “查询”仅读取学校记录，不提交。“签到”独立于查询，打开确认弹窗，核对坐标并勾选实际位置后再点“确认提交”。
7. 每次确认获取新操作票据、发送一次签到请求，即使当天已有记录或不在时段内，也让学校返回校验结果。不会自动重发；账号会话、网络或取票失败仍可能阻止请求送达。
8. 页面展示本次学校返回码、说明以及回查的当天状态。已有 `CHECKED_IN` 不证明本次票据有效，学校拒绝不会被回查的已有记录掩盖。结果不明时先到官方入口核对。

## 手机网络、会话和重复提交

- 学校只读接口会优先直连，并在系统配置了代理时竞争可用线路，短期复用成功线路；VPN 由 Android 系统处理。登录网页和地图使用系统 WebView 的网络设置。网络不可用或代理本身阻断学校连接时仍可能失败，无法保证所有代理环境均能连接。
- 始终验证 HTTPS 证书，不忽略学校证书错误。网页登录由学校处理，应用不实现密码导出、手动 Cookie 导入或绕过 MFA。
- 会话保存在此应用的 WebView 数据目录，关闭应用后可复用；系统备份已关闭。应用不会把 Cookie 返回给页面或写入仓库，不会从聊天、电脑浏览器导入他人会话。点击“清除会话”可退出。
- 微信刷新凭据由 Android Keystore 的 AES-GCM 密钥加密，保存在应用私有目录；不导出到 WebView、日志或电脑。票据仅在手机进程内保存；每次最终确认重新取票，发送后清除。清除微信授权只删除本机副本，不等于服务端撤销授权。认证材料均不能承诺永久有效。
- 新版手动提交不再按日拦截。每次最终确认仅提交一次；超时不自动重发，但新的手动确认会发送新请求，请先核对未知结果。
- 手机版地图改用高德 GCJ-02 底图，选点直接以 GCJ-02 提交，不再重复转换。0.1.0 版保存的 WGS84 位置会自动转换一次并标记为 GCJ-02。沙河和清水河预设点由旧版 WGS84 预设转换而来。不能保证地图、围栏和学校地址完全一致，请核对学校返回地址。没有伪造 GPS、定位精度或传感器测量数据。
- 底图地址参考[高德官方瓦片示例](https://lbs.amap.com/demo/javascript-api-v2/example/thirdlayer/functile)，坐标依据[高德 GCJ-02 说明](https://developer.amap.com/api/javascript-api-v2/guide/abc/basetype)。已验证不使用代理可返回地图图片；服务端仍可能调整访问策略，请遵守地图服务条款，不批量下载瓦片。

## Android Studio 编译

在 Android Studio 中选择 **Open**，打开本仓库的 `android` 目录。需要 JDK 17 或更新版本（推荐 Studio 自带 JDK 21）、Android SDK Platform 36.1、构建用 Python 3.13 和 Git。首次构建下载 Chaquopy 17.1、cryptography 42.0.8 的 Android 预编译包与 certifi，不需要 NDK 或在手机装 Python。Gradle Wrapper 已提交。

Windows 可先在仓库根目录执行 `python setup_wechat.py`，构建会使用隔离的 Python 3.13；也可将 `CHAQUOPY_BUILD_PYTHON` 设为已有 Python 3.13 的可执行文件路径。`prepare_android_wechat.py` 仅提取固定提交的四个协议模块，生成于被 Git 忽略的 build 目录；不包含上游签到入口或用户凭据。源自 [MioYiSama/moon-uestc](https://github.com/MioYiSama/moon-uestc) 的协议代码不被本项目重新声明为 MIT。后续分发应核对上游授权。

连接开启 USB 调试并已授权的手机，选择 `app` 后点击 Run。也可在 `android` 目录执行：

```powershell
.\gradlew.bat assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
adb shell am start -n cn.lcx.goodnightuestc/.MainActivity
```

macOS/Linux 使用 `./gradlew assembleDebug`。SDK 路径通过本机 `ANDROID_HOME` 或未提交的 `local.properties` 配置。不要提交 SDK 路径、私钥或手机数据。工程允许当前 Windows 中文目录；如果本机 SDK 工具无法处理中文路径，可把仓库克隆到英文目录。

预编译 APK 使用维护者本机调试签名，适合试用；签名私钥没有上传。自己编译或下载 GitHub Actions 的 APK 使用的签名可能不同，无法直接覆盖安装，需要自行处理签名或卸载旧版（会丢失会话和本机标记）。仓库 `downloads/SHA256SUMS` 提供安装包校验值。

## 账号库（0.2.7）

学校登录 → 微信扫码授权 → 选择本人实际位置 → 确认签到。只有本次提交被学校接受，且复查明确已签到、无异常标记并有签到时间后，页面下方才出现“把此账号加入账号库”。点击后在本机加密保存学校会话、微信授权及位置；不保存学校密码或已使用票据。

以后点击“切换本机账号”选择使用。相同学号再次保存会更新已有账号，不新增重复项；最多20个账号。会话或微信授权失效时仍需重新登录及授权。保存提示只在当前应用进程中保留，未点击保存就结束进程需要再次完成签到流程。

公开安装包不预置任何账号或测试凭据。相同包名和相同签名的 APK 可覆盖安装，保留原本机账号库及 Keystore 密钥；不要先卸载或清除数据。自行编译通常使用不同签名，无法直接覆盖维护者安装包。

## 诊断日志（0.2.7）

“操作状态”区域提供“复制日志”，出错后点击即可复制脱敏诊断文本，无需重新登录或再次生成二维码。日志按每次操作划分：

- 最近3轮异常保留详细记录，每轮最多约12 KB；网络异常、授权被拒、未知结果及未能复查确认的提交均保留。
- 最近20轮正常操作只留一行摘要，不删除此前异常。包括成功查询、成功授权、提交成功且复查确认，以及取得本次新票据后返回4006且复查仍为PENDING的时段拒绝。
- 正在运行的一轮最多约16 KB，生命周期缓冲约2 KB；日志文件和复制文本均控制在64 KiB以内，超限优先丢弃最早内容。保存时间取决于操作次数，不按天过期。
- 进程被结束的未完成轮次在下次启动时标记为interrupted并保留。旧版日志会作为一轮历史异常迁移，保留其最后约12 KB。

日志记录固定阶段、接口代号、路线、耗时、HTTP/业务码和异常类型，不记录密码、Cookie、微信凭据、二维码、最终票据、学号、完整URL或经纬度。接口代号包括qr_create、qr_poll、oauth_callback、credential_refresh、login_buffer、mmtls_code、school_identity、check_bind和school_ticket。Python授权连接当前走直接连接；学校业务查询可使用系统代理或直连。

4006的压缩属于正常业务结果归档，不等于证明后端所有票据校验均通过。“已经签到”若无法明确确认本次提交的授权和结果，仍保留详情，不根据已有记录就删除。日志足以区分主要失败环节，但不能保证解释服务端所有内部原因。
