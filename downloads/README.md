# 直接安装

[下载 GoodnightUESTC-Android.apk](https://github.com/LCX-luo/GoodnightUESTC/raw/refs/heads/main/downloads/GoodnightUESTC-Android.apk)

Android **8.0 及以上**，版本 **0.1.1 测试版**，约 1 MB。APK 可直接转发给其他人安装，各自使用本人学校账号登录，不包含维护者账号、密码或会话。

此版采用国内高德底图，GCJ-02 选点直接提交，不重复转换。安装后依次使用：**学校账号登录 → 完成登录，返回检查 → 地图选择本人实际位置 → 只读预检查 → 预检查并签到 → 核对并最终确认**。

首次试用请先运行“在线检查”和“只读预检查”，这两个操作不会提交签到。正式签到结果需以学校最终记录为准。[完整说明和免责声明](../android/README.md)。

安装包使用维护者本机调试签名；签名私钥不在仓库，适合当前试用。更新时优先使用此目录维护者发布的 APK，自己编译的签名可能不同。校验文件见 [SHA256SUMS](SHA256SUMS)。
