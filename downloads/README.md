# Android 直接安装

[GoodnightUESTC-Android.apk](GoodnightUESTC-Android.apk) · [SHA256SUMS](SHA256SUMS)

版本 **0.2.1 测试版**，Android 8.0+，arm64-v8a / x86_64，约 39 MB，不含学校账号、密码或微信凭据。

本次修复微信扫码回调和轮询超时，拆开查询与签到。已通过构建、lint、29 项真机模拟断言及 5 项桌面协议模拟测试；手机真实授权及正式签到尚待复测。

使用顺序：**学校登录 → 本人绑定微信摄像头扫码授权 → 等待取票成功 → 地图选本人实际位置 → 查询（只读）或签到 → 核对坐标并最终确认**。

目前二维码不接受同手机相册识别，需要另一屏幕展示后摄像头扫描；未实现直接跳微信完成授权。已保存的有效凭据可复用刷新，不保证永久有效。每次最终确认会获取新票据并提交一次请求，即使当天已签到也会交由学校判断，不自动重发。

使用国内高德 GCJ-02 底图，不需要 Root。第三方协议不保证没有风控，结果以学校记录为准。请按实际位置和学校规定操作。

APK 使用维护者调试签名，适合试用；覆盖安装可保留原资料。自行编译签名可能不同。详情与免责声明见 [Android 教程](../android/README.md)。
