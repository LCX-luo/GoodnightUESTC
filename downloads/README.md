# 直接安装

**当前为实验 APK：用户实测微信拒绝同机截图/相册识别，需摄像头扫描。手机路线已暂停完善，不能宣称独立同机授权可用；建议先使用电脑端。**

[本地 GoodnightUESTC-Android.apk](GoodnightUESTC-Android.apk)

Android **8.0 及以上、64 位 ARM 或 x86_64**，版本 **0.2.0 测试版**，约 39 MB。本次仅本地构建，尚未推送 GitHub；远端旧 APK 不会自动更新。不包含账号、密码或会话。

此版采用国内高德底图，GCJ-02 选点直接提交，不重复转换。安装后依次使用：**学校账号登录 → 完成登录，返回检查 → 显示微信二维码并截图 → 微信扫一扫从相册识别并授权 → 返回应用确认取票成功 → 地图选择本人实际位置 → 只读预检查 → 预检查并签到 → 核对并最终确认**。同机相册识别受微信策略影响，不保证可用；必要时由另一台设备展示二维码再扫描。

首次试用请先运行“在线检查”和“只读预检查”，这两个操作不会提交签到。正式签到结果需以学校最终记录为准。[完整说明和免责声明](../android/README.md)。

已完成真机模拟测试，手机真实微信授权和正式签到仍待验证。内置第三方微信协议，不需要 Root，但不能保证没有风控。

安装包使用维护者本机调试签名；签名私钥不在仓库，适合当前试用。更新时优先使用此目录维护者发布的 APK，自己编译的签名可能不同。校验文件见 [SHA256SUMS](SHA256SUMS)。
