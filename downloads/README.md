# Android 直接安装

[GoodnightUESTC-Android.apk](GoodnightUESTC-Android.apk) · [SHA256SUMS](SHA256SUMS)

版本 **0.2.7**，Android 8.0+，arm64-v8a / x86_64。安装包不含学校账号、密码或微信凭据。

学校登录 → 本人绑定微信摄像头扫码授权 → 地图选本人实际位置 → 确认签到。提交成功并复查确认后，可点击“把此账号加入账号库”；以后使用“切换本机账号”选择，相同学号保存会更新。所有资料仅在本机加密保存。

“复制日志”保留最近3轮异常详情、20条正常摘要，总容量约64 KiB。正常操作不会删除以前的异常。详见[账号库及诊断教程](../android/README.md)。

二维码需要摄像头扫描，目前未实现直接跳微信授权，也不保证相册识别。有效微信凭据可复用刷新，不保证永久有效。使用国内高德GCJ-02地图，不需要Root；第三方协议不保证没有风控，必须按实际位置和学校规定操作。

与此前维护者APK保持同包名、同调试签名，直接覆盖安装可保留原账号；不要先卸载或清除数据。安装包仍使用调试签名，适合试用；自行编译的签名可能不同。

0.2.7通过构建、lint、13项协议模拟测试及14项Java日志存储断言。账号库功能在0.2.6通过51项真机模拟断言；0.2.7未进行新一轮真机安装或正式签到。
