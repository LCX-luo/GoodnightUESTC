# 账号资料库与 ESP32 接入

## 准备账号

1. 启动本机网页，打开 `http://127.0.0.1:8090/`。旧 `/accounts` 地址自动跳转统一工作台。
2. 顶部选择已有账号，或点击“新建账号”，填写备注，完成学校登录与绑定本人微信扫码授权。
3. 地图选择本人实际位置，保存位置后点击“保存 / 更新到账号库”。
4. 选择后可更新同一账号的学校登录、微信授权及位置。下方支持只读查询与一次正式签到测试；未保存的新草稿不能提交。

每个账号有独立目录、加密密钥、会话、微信凭据与 CSRF。页面不显示 Cookie、code、token 或票据，不提供凭据明文导出。签到需本人明确确认；请求按页面所选账号上下文路由，不把其他账号的材料复制过来。学校密码不写入资料库。账号目录位于 `private-data/profiles`，不能上传。

## ESP32 接手入口

请从 [ESP32 关键组件与 Agent 部署指引](../esp32/README.md) 开始。公开目录提供核心组件、示例分区、公共测试向量和 USB 配置工具；由读者的 Agent 根据实际芯片、Flash、网络与工程环境接入。

设备账号必须逐个获得本人授权，配置的地点应为本人实际位置。默认导入关闭自动调度；先逐账号验证只读取票，再确认真实提交，最后才考虑启用每日任务。code 与操作票据每次新取，不能当长期常量。

## 当前验证边界

资料库隔离、地图、显式保存及更新已有测试。设备已实测原生自检、两账号取票、正式提交和结果复查；手机更新本人授权到 ESP32 的链路已确认。时段外真实票据返回4006，随机票据对照返回46002，均无新增记录。时段内新建签到、真实定时执行和跨日仍待验证。

手机管理关键代码、依赖、接入接口和踩坑记录见 [手机伴随端 Agent 教程](../esp32/phone-companion/README.md)。不提供使用者私人 App、编译固件、设备配置或通信密钥。

资料库保存状态不代表凭据当前仍有效。微信刷新授权可能失效；接口变更或授权撤销后仍需本人重新操作。
