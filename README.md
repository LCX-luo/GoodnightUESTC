# 晚安成电：三种使用方式

## 1. Windows 网页版

需要 **Windows、Microsoft Edge、Python 3.10+、Git**。首次安装和授权需要联网，不需要 Docker、Node.js 或地图 Key。

```powershell
git clone https://github.com/LCX-luo/GoodnightUESTC.git
cd GoodnightUESTC
python bootstrap.py --install-only
.\.venv\Scripts\python.exe setup_wechat.py
.\start.cmd
```

授权组件会在项目私有目录安装隔离的 Python 3.13。安装完成后，后续直接运行 `start.cmd`。

1. 打开 `http://127.0.0.1:8090/`，保留启动窗口。
2. 输入学校账号密码，点击“用 Edge 登录并导入”，在独立窗口完成学校要求的验证码或验证。
3. 点击“微信授权并测试取票”，用已在智慧学工绑定当前学校账号的本人微信扫码确认，等待取票成功。
4. 地图选择本人实际位置并保存。地图选点自动从 WGS-84 转为学校 GCJ-02；手动输入高德坐标时选择 GCJ-02。
5. **查询**只读查看当天记录、时段和范围；**签到**在核对弹窗、确认实际位置后，申请新票据并发送一次请求。

查询与提交独立。已有记录或时段未开放时，手动确认仍会提交一次，由学校判断；不自动重发。学校业务码、提示和回查状态分别显示。已有 `CHECKED_IN` 不能证明本次票据有效，响应不明时先核对官方记录。

**多账号资料库：** 访问 `/accounts`。顶部选择已保存的完整账号，可重新登录更新；下方新建依次完成学校登录、本人微信扫码、地图选点及保存位置，最后保存添加到库。账号资料分别加密保存，资料库页面本身不提交签到。

关闭启动窗口即停止服务，当前网页版没有每日定时任务。学校或微信授权失效时需更新登录。

## 2. Android 版

[下载 APK](downloads/GoodnightUESTC-Android.apk) · [校验值](downloads/SHA256SUMS) · [详细教程与编译](android/README.md)

当前 **0.2.4**，支持 Android 8.0+ 的 arm64-v8a / x86_64。内置运行环境，不需要 Root、电脑中转或模拟器；使用国内高德 GCJ-02 地图。

1. 安装 APK，通过学校官方页面登录，完成后返回检查。
2. 点击一次“显示二维码 / 验证授权”，用绑定当前账号的本人微信摄像头扫码确认，返回等待取票。
3. 地图选择本人实际位置，或输入 GCJ-02 坐标。
4. 点击“查询”只读查看；点击“签到”并在弹窗最终确认后，发送一次请求并显示学校反馈。

**首次授权需要另一屏幕展示二维码后摄像头扫描。微信可能拒绝同手机相册识别，尚未实现直接跳微信完成授权。** 已保存的有效凭据可免重复扫码取票，不保证永久有效。

切去微信再返回会恢复原任务和进度，短暂轮询断连保留原二维码有限重连。不要连续生成二维码；系统结束整个进程时仍需重新授权。覆盖安装相同签名的更新版可保留资料；当前 APK 使用维护者调试签名。

## 3. ESP32 版

[部署教程与 AI Agent 接手说明](esp32/README.md) · [关键源码](esp32/components/checkin_runtime) · [账号资料库](docs/accounts-and-esp32.md)

**目前是实验源码，设备完整取票、正式提交和跨日运行尚未通过，不能当作开箱即用固件。** 适配经典 ESP32、4 MB Flash、ESP-IDF 5.1.2。仅提供关键组件与通用 Agent 接入指引，不分发个人固件或配置。

1. 按 Windows 教程准备账号库，逐账号完成学校登录、本人微信授权和实际位置保存。
2. 识别开发板、完整备份原 Flash 并核对分区，保护已有分区数据。
3. 按 ESP32 教程配置芯片、IDF 与组件依赖，由本人或 AI Agent 编译本机固件。
4. 刷写后检查原生自检、内存和 Wi-Fi，保持自动签到关闭。
5. 用 `esp32/provision.py` 经 USB 导入账号，逐账号执行不提交签到的取票验证。真实写操作另用 `--submit-once`，需确认授权及实际位置。
6. 完成验证后才考虑 `--enable-schedule`：北京时间每日 21:10 启动，逐账号处理；错过 21:10–21:14 不补签。

新代码先用微信凭据重建学校会话并核对账号，再查询与换票，目标是避免依赖过期的学校 Cookie。重建链已在电脑只读验证，设备版本仍待验证。微信凭据也可能失效。设备 NVS 默认明文，未启用 Flash 加密，设备遗失可能泄露凭据。

## 数据与维护

- 学校密码不写入本工具配置。电脑资料位于 `private-data/` 并加密；Android 微信凭据使用 Keystore 加密。不要分享使用过的完整程序目录。
- 地图选点是用户配置，不代表实时 GPS；缺省定位字段不伪称传感器测量。
- 学校查询会选择可用直连或代理；微信协议还使用直连 TCP，不能保证所有网络可用。不关闭 HTTPS 验证，不自动重发签到 POST。
- 开发测试：`test.cmd`。许可见 [LICENSE](LICENSE)、[第三方声明](vendor/THIRD_PARTY_NOTICES.md) 及各来源说明。
