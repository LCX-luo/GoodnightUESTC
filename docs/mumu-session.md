# MuMu 学校会话读取与电脑 HTTP 请求

此路线在 MuMu 中正常登录官方微信小程序，由电脑读取本人学校 H5 的会话和操作票据，再使用 Python 发起 HTTPS 请求。不会自动点击页面，不会生成或伪造操作票据，不需要 Root 真实手机。MuMu 需要保持运行；目前仍需本人从小程序入口打开官方打卡页面，不是完全脱离微信的登录方案。

## 已验证的范围（2026-10-23）

仅针对本人账号、当天已经存在的成功记录进行授权测试，使用相同位置，每次回查记录 ID 和签到时间均未改变：

| 电脑 Python 请求 | 返回业务码 | 返回提示 |
| --- | --- | --- |
| MuMu Cookie，不带操作票据 | 46001 | 请从微信小程序重新进入打卡应用后提交 |
| MuMu Cookie，携带操作票据 | 4006 | 今日已完成打卡 |
| 重复使用同票据及 MuMu Cookie | 4006 | 今日已完成打卡 |
| 同账号另一有效 Edge 会话，携带 MuMu 票据 | 4006 | 今日已完成打卡 |

重新从小程序首页进入后观察到票据发生变化。票据是 43 字符的不透明值，不是可直接解码有效期的 JWT。在这组已签到请求里，票据可重复使用、可配对同账号另一个 SESSION，并可从电脑 Python 发出。所用 UA 来自原桌面配置，不是抓取得到的微信 UA。

**仍未验证：**用此路线首次创建一条新的正常签到记录、成功签到后是否消耗票据、完整有效期、跨账号或其他设备/网络的绑定规则。这些结果不能证明“永久有效”“不限设备”或“无法识别”。

脱敏测试记录只保存在本机 `private-data/ticket-research/`，不会打包或上传。当天测试 POST 的授权额度已用完，常规命令不会重复发送这些诊断请求。

## 使用条件

- Windows，项目现有 Python 环境和依赖。
- 已登录本人账号的 MuMu 实例，微信内打开晚安成电官方页面。
- MuMu 实例开启 Root 后重启，通过 `adb root` 获得 ADB 调试权限。真实手机不需要修改。
- 本机工具曾登录同一账号，用于核对账号与沿用桌面 UA 配置。
- 当前读取器支持已验证的 `appbrand0` WebView 和只有日志、尚未压缩的 Session Storage。若存储转为 `.ldb/.sst`，会明确停止，避免把历史票据当作当前票据。

不要把 Root 当作正常微信登录的替代品；若微信要求验证或重新登录，请在官方界面完成。

## 命令

在仓库目录打开 PowerShell：

```powershell
# 检查：读取学校会话、只读查询当天记录，只输出凭证摘要
.\.venv\Scripts\python.exe mumu_session.py inspect

# 将核对过的会话及票据加密导入本机工具；原加密会话保留一份备份
.\.venv\Scripts\python.exe mumu_session.py import

# 使用电脑页面地图中保存的位置，执行只读预检查
.\.venv\Scripts\python.exe mumu_session.py prepare

# 预检查后要求本人输入“确认提交”，调用原有的单次提交及回查逻辑
.\.venv\Scripts\python.exe mumu_session.py submit
```

多实例可通过 `--serial 127.0.0.1:端口` 指定 MuMu 设置中显示的 ADB 地址；不会自动选择连接的真实手机。若 ADB 服务器重启或 Root 失效，需要重新执行 `adb root`。

`import` 后也可以继续使用本机网页的地图和确认流程。电脑地图中的保存位置与 MuMu 定位设置是两个独立配置，请按本人实际位置核对。定位元数据仍沿用现有脚本默认值，不能称为真实传感器采集结果。

当天已有记录时，`prepare/submit` 会在预检查阶段结束，不发出正式签到请求。提交后结果不明时不会自动重试，先在官方页面核对。票据过期时，应从官方小程序重新进入并重新读取。

此工具仅供本人账号及学校允许的用途；不得用于代签、虚假记录或操作他人账号。
